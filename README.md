# Python Dungeon Crawler

A text-based terminal dungeon crawler game built with Python. Navigate through ASCII dungeons, fight enemies, collect loot, and survive the adventure!

## Features

- **Terminal-based Gameplay**: Play directly in your terminal with ASCII graphics
- **ASCII Dungeon Maps**: Randomly generated dungeons with rooms and corridors
- **Character Stats**: Health, mana, strength, and more
- **Combat System**: Turn-based combat with various enemy types
- **Inventory System**: Collect items, weapons, and potions
- **Terminal Animations**: Smooth animations and visual effects
- **Multiple Levels**: Progress through increasingly difficult dungeons

## Requirements

- Python 3.8+

## Installation

```bash
git clone https://github.com/jaylikescode/python-dungeon-crawler.git
cd python-dungeon-crawler
```

## Running the Game

```bash
python main.py
```

## Controls

- **Arrow Keys** or **WASD**: Move around the dungeon
- **Space**: Interact with items/NPCs
- **I**: Open inventory
- **H**: Help menu
- **Q**: Quit game

## Project Structure

- `main.py` - Game entry point
- `game.py` - Core game logic
- `player.py` - Player character class
- `dungeon.py` - Dungeon generation and management
- `entities.py` - Enemy and NPC classes
- `items.py` - Item and loot system
- `combat.py` - Combat system
- `ui.py` - Terminal UI and rendering
- `animations.py` - Terminal animations and effects
